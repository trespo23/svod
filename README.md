# Свод

Личный планировщик: день, «Отсортировать», план, календарь и цели. Одна страница без сервера, данные хранятся в браузере устройства.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `svod`.
2. Загрузите в него все файлы из этой папки (кнопка **Add file → Upload files**).
3. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две приложение откроется по адресу `https://<ваш-логин>.github.io/svod/`.

## Как поставить на телефон

- **iPhone:** откройте адрес в Safari → «Поделиться» → «На экран Домой».
- **Android:** откройте адрес в Chrome → меню → «Установить приложение».

После первого открытия приложение работает без интернета.

## Данные

- Хранятся только на устройстве, в браузере. Между устройствами не синхронизируются.
- Перенос и резервная копия: «Настройки → Данные».
- Если удалить данные сайта в браузере, записи пропадут: делайте копию.

## Обновление

Замените файлы в репозитории и увеличьте номер версии в `sw.js` (`svod-v1` → `svod-v2`), иначе телефоны продолжат показывать старую версию из кэша.

## Файлы

- `index.html` — всё приложение.
- `sw.js` — офлайн-кэш.
- `manifest.webmanifest`, `icon*.png`, `icon.svg` — установка на телефон и иконка.
